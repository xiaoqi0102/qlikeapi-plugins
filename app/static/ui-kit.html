色彩与排版tokens.css

字号刻度 --fs-*（11/12/13/14/15/18/20/22/26/30）
圆角刻度 --r-*（4/6/9/12/16/999）
动效时长 --dur-*（鼠标悬停看过渡快慢）
正文 --fs-base 13px / 表格与表头 --fs-sm 12px / 辅助文字 .hint（--muted）。数字与代码用 .num / .mono 等宽对齐。**写死 px 一律按 §2.2 就近取档收敛，`make ui-lint` 会拦。**
改色/改字号只改 tokens.css；深色模式在 body.dark 覆盖**同名变量**，组件里不许出现字面量

<div class="acts"><button class="ibtn" title="删除">…</button></div>

徽章与标签.pill / .chip

正常降权异常 原生透传未探测 sub2api (/v1/usage)gpt-image-2
pill＝状态（带圆点更醒目，颜色只有 ok/warn/err/info 四档）；chip＝中性信息（类型、模型名、渠道 key）。状态色不要用来自定义含义，否则一眼看不出好坏。
UI.pill('ok dot', '正常') UI.chip('gpt-image-2')

卡片与 KPI.panel / .stat

面板（标题 + 右上角操作）

面板＝一个自洽的功能块：标题说明「这是什么」，右上角放该块的主操作，内容区只放表格/表单/图表之一。
UI.stat('站点数量', '11', '已启用 11', 'ti-building', '')

表格 / 骨架屏 / 空状态.tb / .sk / .empty

数据表

加载中用 UI.skelTable(列数, 行数)（列宽与真实表格对齐，避免加载完跳动）；无数据用 UI.empty('一句话说明 + 下一步该点什么', 'ti-inbox')

表单.form-control / .sw / .pinp

说明文字写「为什么」，不要重复标签
密钥类字段用 .pinp（等宽 + 打码 + 右侧眼睛切换）：

校验失败：字段下方给具体原因（如「模型名不存在」），不要只把边框变红。
<div class="pinp"><span class="mono">sk-…</span></div>

多选选择器UI.picker · .pk-*

实时回显：（未选）
候选集按插件分组，停用渠道也能选（可能随时恢复）。
什么时候用：字段值是「已存在集合里的若干个」时（模型、渠道、标签、分组）必须用它， 不要用逗号分隔的文本框 —— 手输拼错看不出来，也选不出不存在的项。
UI.picker('#pkModels', {items, selected, placeholder: '全部模型（不限）', onChange: v => …})

反馈toast / confirm / bar / busy

规则：能就地反馈的不要弹窗；破坏性操作必须确认；确认文案写清后果（「删除后调用会立刻 401」）。
进度条（探活/批量任务逐条进度）
UI.bar(32) UI.busy(true) / UI.busy(false)

弹窗UI.modal

弹窗只用于「新建/编辑表单」和「不可逆操作的确认」；展示型信息优先放面板或吐司。表单弹窗宽度 modal-lg，长表单用 modal-dialog-scrollable。 第 4 个参数是显示后回调，挂载 UI.picker 这类需要尺寸的组件必须写在这里。
UI.modal('标题', bodyHTML, footHTML, () => { /* 挂载组件 */ })

工具类.hint / .mono / .num / .acts / .grid2

.hint 辅助说明.mono 等宽（key、路径）.num 数字右对齐
布局：.grid2 两栏、.grid3 三栏（窄屏自动单栏）、.acts 操作横排。 间距统一用 Bootstrap 的 mt-1..4，不要写行内 style。
.grid2 .grid3 .acts .hint .mono .num
